# 📱 PhoneBook Web Application

A Java-based PhoneBook web application using Servlet, JSP, JDBC, and MySQL. This app allows users to register, log in, and manage their personal contacts.

##  Features

- Register & Login
- Add, Edit, Delete, View Contacts
- Session Management

##  Tech Stack

- Java EE (Servlet, JSP)
- JDBC + MySQL
- HTML + Bootstrap + Tailwind
- Apache Tomcat

##  Setup Instructions

1. Clone: `git clone https://github.com/kartikpatankar/PhoneBookApp.git`
2. Import as Dynamic Web Project in Eclipse
3. Create `phonebook` database and run SQL script
4. Update DB config in `DBConnection.java`
5. Run on Tomcat Server
